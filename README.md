# Logitalk1

**LotiTalk**-це простий чат де легко і просто можна користуватися і надсилати фото один одному який був написаний у Visual studios Cood

## спецальні Можливосі
- надсилати власним друзям електроні листи
- передавати зображення і своїх файлів
- підтримує 2-або більше користувачів
- протий інтерфейс і ненавантужує ваш пристрій

## Підтримує
- Python3
- Socket
- Base64
- Pillow
